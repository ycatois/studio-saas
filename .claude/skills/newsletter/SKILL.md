# Newsletter
- Objet : 3 variantes (curiosité, bénéfice, chiffre), 45 caractères max ; pré-header complémentaire.
- Structure : 1 sujet principal utile (avec un vrai apport) · 2 à 3 brèves (nouveauté produit, contenu, ressource externe) · 1 CTA principal.
- Ton conversationnel, signé par une personne.
- Mentions : désinscription, raison de réception.
