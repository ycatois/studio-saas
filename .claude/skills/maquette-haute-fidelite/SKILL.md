# Maquettes haute fidélité
- Partir des wireframes validés et de `marque/charte/tokens.css`.
- Une page HTML autonome par écran dans `5-cadrage/maquettes/` (ou `marketing/landing/maquettes/` pour la vitrine), contenu réaliste en français (jamais de lorem ipsum), états clés (vide, rempli, erreur), version **bureau et mobile** (responsive).
- **Propositions** : quand l'utilisateur demande des options, 2 ou 3 variantes d'un même écran clairement différentes (mise en page, hiérarchie), avec en tête de page ce que chaque variante privilégie.
- Un `index.html` qui liste toutes les maquettes avec leur statut (proposée / retenue / à revoir).
- Captures PNG bureau + mobile de chaque maquette (skill captures-ecran) pour les relectures et les briefs.
- Accessibilité : contrastes, tailles de cibles, ordre de lecture ; poids léger.
