# Analyse de prix
- Relevé daté des grilles concurrentes (plans, métrique de facturation : par utilisateur, par usage, forfait).
- Identifie la métrique de valeur la plus alignée avec le bénéfice client.
- Propose 3 plans (entrée, cœur, premium) en B2B, prix HT, mensuel avec option annuelle −20 % (cadre par défaut de CLAUDE.md), + éventuel essai, avec justification.
- Estime la disposition à payer (questions Van Westendorp à poser en interview).
