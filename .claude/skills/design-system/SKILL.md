# Design system
Source : `marque/charte/tokens.json` (charte graphique du directeur-artistique) — le design system en dérive et ne la contredit pas.
Tokens (couleurs avec contrastes vérifiés AA, typographie système ou 1 police max, échelle d'espacements, rayons), composants (bouton, champ, carte, tableau, alerte, modale, navigation), états, mode sombre, règles d'icônes et d'images (poids).
Livrable en Markdown + fichier de tokens (CSS variables ou JSON).
