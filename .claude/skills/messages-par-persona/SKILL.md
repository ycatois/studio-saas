# Messages par persona
Pour chaque persona, tableau par étape (inconscient du problème → conscient du problème → compare les solutions → prêt à acheter → client) :
- Message clé · preuve · objection probable · réponse · format de contenu adapté · CTA.
Ajoute la **matrice des objections** : objection · fréquence · réponse courte · preuve · où la traiter (landing, FAQ, email, démo).
