# Post LinkedIn

## Avant d'écrire
- Lire `marque/voix-fondateur.md` (post personnel) ou `marque/ton-de-voix.md` (page entreprise).
- Un post = une idée = un lecteur cible = un objectif (notoriété, conversation, trafic, recrutement de testeurs).

## Structure
1. **Accroche (2 premières lignes, avant le « voir plus »)** : tension, chiffre surprenant, aveu, contre-pied, question précise. Pas de « Je suis ravi de vous annoncer ».
2. **Corps** : histoire vécue ou démonstration, phrases courtes, une ligne vide entre les blocs, concret (noms de situations, chiffres, erreurs).
3. **Leçon / idée à retenir** en une phrase.
4. **Fin** : question ouverte qui appelle une vraie réponse, ou CTA doux. Le lien éventuel va en commentaire si l'utilisateur le souhaite.

## Formats à faire tourner
- Histoire (échec → déclic → leçon)
- Coulisses du build (« build in public » : chiffres, décisions, galères)
- Opinion argumentée (un contre-pied défendable sur le secteur)
- Liste utile (« 7 erreurs qui… »)
- Avant/après d'un client (avec accord)
- Annonce produit racontée par le problème résolu

## Règles
- 800 à 1 500 caractères en général ; 3 hashtags maximum ; emojis rares et fonctionnels.
- Pas de formules creuses (« game changer », « révolutionnaire ») ni d'engagement bait.
- Toujours livrer **3 accroches alternatives** + le post + une suggestion de visuel + 2 commentaires de relance que l'auteur peut poster.
- Fichier : `marketing/linkedin/AAAA-MM/<date>-<slug>.md`, `statut: brouillon`.
