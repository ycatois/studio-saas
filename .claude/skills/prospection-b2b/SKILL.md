# Prospection B2B
- **Profil client idéal** : secteur, taille, rôle, déclencheurs (recrutement, levée, nouvelle réglementation, outil abandonné).
- **Séquence** (sur 3 semaines) : invitation LinkedIn sans pitch → email 1 personnalisé (observation précise + problème + question) → relance valeur (ressource utile) → cas client → dernier message de clôture polie.
- Messages de 60 à 120 mots, une seule question, pas de pièce jointe au premier contact.
- RGPD B2B : adresse professionnelle, lien avec la fonction, mention d'opposition simple.
- **Script de démo** : découverte (questions) → démonstration centrée sur leur cas → objections → prochaine étape datée.
- Fichier de suivi pipeline : compte · contact · étape · prochaine action · date.
Tout est préparé ; l'envoi est fait par l'utilisateur.
