# Copywriting
- **PAS** : Problème → Agitation → Solution. Pour landing et posts douleur.
- **AIDA** : Attention → Intérêt → Désir → Action. Pour pages de vente.
- **BAB** : Avant → Après → Pont. Pour études de cas et emails.
- **4U** pour les titres : Utile, Urgent, Unique, Ultra-spécifique.
Règles :
- Bénéfices avant fonctionnalités ; un chiffre précis vaut mieux qu'un adjectif.
- Phrases courtes, voix active, vocabulaire du client (cf. personas).
- Un texte = un objectif = un CTA.
- Toujours proposer 3 variantes de titre / accroche.
- Interdits : promesses invérifiables, fausse urgence, faux témoignages.
