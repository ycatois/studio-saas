# Unit economics
- ARPA, marge brute, churn mensuel → LTV = ARPA × marge / churn.
- CAC par canal (dépenses + temps valorisé) ; ratio LTV/CAC (cible ≥ 3) ; payback CAC (cible ≤ 12 mois).
- Sensibilités : quel levier améliore le plus le ratio ?
- Signale toute donnée estimée.
