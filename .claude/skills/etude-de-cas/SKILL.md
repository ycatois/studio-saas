# Étude de cas
Structure Avant → Pendant → Après : contexte du client · problème et son coût · pourquoi ils ont choisi · mise en place · résultats chiffrés · citation · ce qu'ils diraient à un pair.
Préparer d'abord le questionnaire d'entretien client. Déclinaisons : page web, PDF, post LinkedIn, slide commerciale. Jamais de résultats inventés ; validation du client avant publication.
