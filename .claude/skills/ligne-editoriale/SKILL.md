# Ligne éditoriale
- Objectifs du contenu (notoriété, acquisition SEO, confiance, conversion, rétention).
- Cibles et leurs questions (top 30 questions réelles issues des signaux, des interviews, du support).
- **3 à 5 piliers** : thème · pourquoi il compte pour la cible · lien avec le produit · formats · mots-clés.
- Répartition type : 40 % éducatif, 25 % expertise/opinion, 20 % preuve (cas, chiffres, coulisses), 15 % produit.
- Formats par canal, fréquence soutenable (mieux vaut 1 article/semaine tenu que 5 abandonnés).
- Règles éditoriales : sources, ton, longueur, visuels, CTA par type.
