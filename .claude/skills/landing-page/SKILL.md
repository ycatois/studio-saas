# Landing page
Sections dans l'ordre :
1. **Hero** : titre = résultat pour la cible (pas le nom du produit) · sous-titre = comment + pour qui · CTA principal · visuel du produit en action · micro-preuve (logos, note, nombre d'utilisateurs si réel).
2. **Problème** : les 3 douleurs dans les mots du client.
3. **Solution** : 3 bénéfices, chacun avec la fonctionnalité qui le permet.
4. **Comment ça marche** : 3 étapes.
5. **Preuves** : témoignages réels, cas, chiffres, garanties (données en France/UE, RGPD, sobriété si pertinent).
6. **Pour qui / pas pour qui.**
7. **Tarifs** (ou lien).
8. **FAQ** (objections).
9. **CTA final.**
Règles : test des 5 secondes (on comprend quoi, pour qui, quoi faire), un seul objectif de conversion, formulaire minimal, vitesse. Livrer le texte complet + 3 variantes de hero pour A/B test.
