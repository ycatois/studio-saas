# Carrousel LinkedIn
8 à 12 slides, une idée par slide, 25 mots max par slide.
1. Couverture : promesse forte + bénéfice.
2. Le problème / l'enjeu.
3 à N-2. Étapes, erreurs, méthode, exemples (numérotés).
N-1. Récapitulatif.
N. Appel à l'action (suivre, commenter, ressource).
Livre : texte de chaque slide + indications visuelles (cohérentes avec le design system) + le post d'accompagnement. Option : générer le PDF en HTML → PDF si demandé.
