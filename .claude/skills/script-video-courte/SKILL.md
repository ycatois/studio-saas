# Vidéo courte
- 0–3 s : accroche visuelle et verbale.
- 3–60 s : un seul message, 3 points maximum, démonstration à l'écran si produit.
- Fin : leçon + CTA.
Format : tableau temps · ce qu'on voit · ce qu'on dit · texte à l'écran. Sous-titres obligatoires. Prévoir aussi la version texte du post qui accompagne.
