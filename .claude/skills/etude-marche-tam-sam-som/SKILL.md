# TAM / SAM / SOM
- **Bottom-up d'abord** : nombre de clients cibles (source) × panier annuel estimé (lié à l'analyse de prix).
- TAM = tout le marché adressable ; SAM = la part atteignable avec notre offre/zone/canaux ; SOM = part réaliste à 3 ans (justifie le % par la capacité commerciale).
- Contrôle top-down avec un rapport sectoriel si disponible ; explique les écarts.
- Tableau des sources : donnée · valeur · source (URL) · date · fiabilité.
- Tendances : 3 à 5 tendances qui font croître ou décroître le marché, sourcées.
