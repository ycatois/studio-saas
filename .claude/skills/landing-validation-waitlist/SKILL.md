# Landing de validation
- But : prouver la demande avant de coder. Métrique : taux visite → inscription (repères indicatifs : < 5 % faible, 5–15 % correct, > 15 % fort, à moduler selon la source de trafic).
- Contenu : promesse claire, douleurs, aperçu (maquette), « rejoignez la liste d'attente / accès anticipé », éventuellement une question de qualification (rôle, taille, urgence) ou une pré-commande / acompte remboursable pour un signal plus fort.
- Honnêteté : indiquer clairement que le produit est en préparation.
- Trafic : posts LinkedIn du fondateur (build in public), communautés de la cible, prospection ciblée, petit test ads plafonné.
- Après inscription : email de remerciement + 1 question ouverte (« quel est votre plus gros problème avec… ? ») → mine d'or pour les interviews.
- Résultats consignés dans `2-marche/validation.md` et utilisés dans le scoring.
