# Éco-conception
Poids et nombre de requêtes par page, images/vidéos, polices, scripts tiers, cache, fonctionnalités inutiles, compatibilité anciens terminaux, hébergement, données conservées. Recommandations chiffrées et priorisées. C'est aussi un argument marketing : le documenter.
