# Test A/B
Hypothèse (« si… alors… parce que… ») · une seule variable · métrique principale · taille d'échantillon réaliste (sinon, préférer un test qualitatif) · durée · critère de décision. Analyse : résultat, significativité, décision, apprentissage consigné.
