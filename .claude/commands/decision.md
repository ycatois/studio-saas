Venture concernée : déduis-la de `$ARGUMENTS` (premier mot = slug) ; s'il n'y a qu'une venture active, prends-la ; sinon demande.

1. **comite-decision** rédige `4-decision/memo.md` (skill memo-decision).
2. Présente à l'utilisateur : recommandation, score, 3 pour, 3 risques, conditions, MVP, budget/délai, plan d'acquisition des 100 premiers utilisateurs.
3. **ARRÊTE-TOI.** Demande explicitement : « GO, NO-GO ou PIVOT ? »
4. Uniquement après sa réponse : consigne la décision (date, conditions) dans STATUT.md et le mémo. GO → propose `/lancer`. NO-GO → phase « archivée ». PIVOT → nouvelle fiche idée liée.
Ne lance aucune phase suivante dans ce même tour.
